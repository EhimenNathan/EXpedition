# Post-v20 prospective gates — 2026-10-27

All results below use site-disjoint out-of-fold predictions or the paired
26-region full-system rehearsal. None passed the submission gate.

## Satellite composition drift

Training has 20/129 (16%) large satellite regions, while the public structure
has about 57%. Importance weighting confirms that these regions are harder
(deployed score 0.2944 versus 0.3857 on small scenes), but re-tuning thresholds
and framing under the public mix is unstable:

- weighted deployed 0.3473; nested 0.3538 (+0.0065);
- unweighted deployed 0.3797; nested 0.3809 (+0.0012);
- outer fold 3 regresses 0.2695 -> 0.2428, and fold 0 also regresses.

The drift is real. The proposed post-processing response is rejected because it
does not generalize across untouched folds.

## Satellite shading consistency

The leave-one-out scene illumination feature has weak signal, but fails the
non-regression gate:

- deployed 0.3797; nested 0.3801 (+0.0004);
- best pooled fixed lambda 0.25 scores 0.3816 (+0.0019);
- worst outer-fold change is -0.0027;
- site bootstrap P(gain > 0) is 0.82, 90% CI [-0.0015, +0.0052].

Rejected as too small and fold-unstable.

## Aerial DINOv2 verifier parity

The earlier verifier filtered raw overlapping-tile detections before fusion.
The corrected implementation uses:

1. FCOS detections on every chip;
2. fusion within each source image;
3. attachment of each fused candidate to the chip with greatest border margin;
4. the same 224 px JPEG-resampled crop used in OOF;
5. the frozen DINOv2-S verifier.

The corrected build completed the 26-region rehearsal in 290.5 s. It emitted
3013 features versus 3065 for v20 and scored 0.5362605 versus the prior full
rehearsal anchor of about 0.5352: only +0.0011 overall. The archive was deleted
and the verifier remains disabled in the checked-in configuration. The reusable
implementation is retained behind the `fort_verifier` config key.

## Decision

Keep v20 as the public-score anchor and the watchdog build as private-set
insurance. Do not submit any of these three changes.
